### 🚀 Featured Project Spotlight

#### 🎰 **AgentSmark: Sports AI & Gambling Simulation Platform**
> *Real-time sports streaming metadata parser, AI fixture search, and gamified sports betting simulator with a Windows XP / retro N64 aesthetic.*

* **Frontend**: React 19, Vite, Custom Windows XP GUI & N64 retro sports icon pipeline.
* **Backend**: Python 3.11, FastAPI, Google Gemini AI parsing, TMDB API integration, SQLite & Supabase.
* **Infrastructure**: Containerized with Docker Compose, Nginx reverse proxy, automated CI/CD deployment to AWS Lightsail via GitHub Actions.
